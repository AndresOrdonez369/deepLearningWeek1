### Cómo usarlos

1. Clic en **Open in Colab** y entra con tu cuenta de Google.
2. **Archivo → Guardar una copia en Drive**; si no, tus cambios se pierden al cerrar la pestaña.
3. Ejecuta primero la celda **Configuración** y luego sigue en orden con `Shift + Enter`.
4. Cada sección sigue el mismo orden: qué vas a hacer → la necesidad → ejemplo → el nombre → la fórmula («Léelo así») → **Qué hace este código** → **🔮 Antes de ejecutar: ¿qué crees que saldrá?** → ejecuta → **Qué deberías ver** (con los números exactos) → **💭 Para pensar** (las respuestas están plegadas en «Ver respuesta»).
5. Las celdas **🧪 Experimenta** son opcionales: cambia el único valor marcado (por ejemplo `exigencia = 70   # try 80`) y vuelve a ejecutar.
6. Si algo falla, cada notebook tiene al inicio un recuadro **🛟 Si algo falla**. Si ya sabes Python, puedes saltarte la **Parte 0**.

Los notebooks se publican ya ejecutados, así que puedes ver todas las salidas y gráficas antes de correrlos.

Para correrlos en tu computador en vez de Colab: `pip install -r requirements.txt` (Python 3.10 o superior).

Los datos de los ejemplos son ficticios y se generaron solo con fines educativos.
